# GitHub Repository Security API Tool

A beginner-level Python project that uses the GitHub REST API to fetch and display repository information.

This project was created to practice:

- API requests using Python
- JSON data handling
- Exception handling
- Working with external services
- Basic security-focused scripting concepts


## Features

- Takes a GitHub repository name as user input
- Fetches repository details using GitHub API
- Displays:

  - Repository name
  - Full repository name
  - Description
  - Star count
  - Open issues count
  - Fork count


## Error Handling

The script handles common API failures:

- Connection errors (internet/network problems)
- Request timeouts
- HTTP errors (invalid repository or API errors)


## Technologies Used

- Python 3
- Requests library
- GitHub REST API
